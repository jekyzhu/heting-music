# 安卓智能音效：第一阶段

仅开发 Android，基于现有合听 0.7.1。开发分支为 `feature/android-smart-eq`。
这是开发中的源码阶段，尚未作为新安装包发布。

## 本阶段实现

- 侧边栏“智能音效”入口；默认关闭，可独立开关。
- 原声、摇滚、民谣、流行、古典、电子六种预设。
- 五个参考频率的手动调节（±6 dB），自动保存“我的音效”。
- 手动选择或调节退出自动模式；自动模式不覆盖保存的个人曲线。
- 自动模式读取明确的 genre/genres/style/styles 标签；缺失、不支持或风格冲突时使用原声。
- 使用 Android Equalizer，按设备实际频段进行对数频率插值。预留正增益余量，
  曲线切换约 400 毫秒；耳机和手机实现差异会影响结果。
- 跟随播放器会话建立、变更和销毁。后台播放沿用原播放器服务。
- 不支持均衡器或失去控制权时显示状态，继续原有播放。

## 复用的开源代码

复用现有 React Native Track Player 4.1.1 和其 KotlinAudio v2.1.0 播放链。
KotlinAudio 的固定版本源码及原 Apache-2.0 许可证保存在
`android-app/third_party/kotlinaudio/`，仅在播放器的会话变化及销毁处添加应用内广播。
Gradle 替换同版本依赖，不改 node_modules，不使用反射或全局 session 0。
新增的均衡器通过 Android 公共 API 实现，不要求 Root，也不录制麦克风。

## 验证与下一阶段

本地运行类型检查和音效规则/状态测试；GitHub Actions 配置了 Android Kotlin 编译。
以 Actions 的实际运行结果为准，源码提交本身不代表原生构建或真机验证成功。

**当前尚未实现音频内容的模型识别。** 网易云/QQ 歌曲若不带明确风格标签，
自动模式会保留原声，不能称为“已经听出摇滚或民谣”。下一阶段需要评估可嵌入
Android 的模型与模型许可证、合法可用的解码音频输入、耗电及识别置信度，
再接入当前的预设策略。手机上的后台、蓝牙、切歌、开关和听感均待真机验证。

验收步骤：播放歌曲 → 开启音效 → 切换摇滚/民谣并观察状态 → 手动调节并切歌 →
重启检查个人曲线 → 检查自动模式在有/无风格标签时的行为 → 关闭音效比较原声。
测试过程中注意预留余量可能降低整体音量，不应以音量更大作为音质更好的判断。

后续每个可验证阶段提交到 GitHub，提供提交链接及验证边界；保留当前稳定主分支。
