# 合听 Android 0.8.2 音效强度与原声对比

0.8.1 已经在用户小米 17 Ultra 上确认可以播放。用户随后反馈音效切换不够明显。

本次增加“自然 / 标准 / 鲜明”三档预设强度，自然、标准分别为原曲线的 0.65 / 1 倍；鲜明一般为 1.7 倍，摇滚鲜明档根据用户“有线耳机、低音与摇滚冲击感更强”的反馈单独调校，强调低频与鼓点。按 0.5 dB 量化，仍限制在 ±6 dB 内。默认鲜明；可选择标准恢复之前的预设幅度。自动音频识别和手动预设使用同样的强度。已有“我的音效”保持保存的实际 dB 值，不额外放大。

增加“对比原声 / 返回音效”：同一首歌连续播放时，只旁路本应用均衡器，不暂停歌曲、不改变音量滑块，不清除识别结果，不写入音效设置。离开页面、切到后台或修改预设时恢复音效。均衡器仍保留增益余量，因此原声与音效的整体音量可能不同。

“鲜明”下摇滚参考点为 [6, 4, -2, 2, 4] dB，民谣为 [-1.5, 1.5, 3.5, 1.5, 0] dB。实际频段按设备均衡器插值，听感也受外放/耳机及设备系统音效影响。界面状态会核对均衡器是否启用且持有控制权，不只显示预设名称。

建议试听：播放一首熟悉的歌曲，进入智能音效并启用，手动选择摇滚、鲜明，然后用“对比原声”来回试听；再试民谣。确认预设差别后再打开自动切换；若识别结果仍不确定，自动模式会保留原声。

验证包括 TypeScript、播放器/音效/账号回归测试、原生预设曲线测试、Android 10 与 16 实际播放测试。模拟器和数值测试不代替用户设备的最终听感验收。
