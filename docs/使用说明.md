# 合听 0.7.1 · QQ 登录与并列歌单开发体验版

开发体验版 · 仅限指定好友体验，请勿公开传播。
音乐服务与播放权限以本人平台账号为准。本声明说明体验范围，不增加邀请码或身份白名单。

## 安装与升级

1. 在下载页下载“合听-0.7.1-并列歌单体验版.apk”。适用于 ARM64 安卓手机，最低 Android 7.0。
2. 推荐直接用手机浏览器打开下载页；电脑页面也有手机二维码。
3. 点击 APK 安装，按提示允许浏览器或文件管理器安装此来源应用。已装 0.7.0 可直接覆盖升级，不用先卸载。
4. 应用 ID、签名和账号会话路径保持一致，覆盖升级会保留本机已保存的网易云登录状态。系统自身清理数据或卸载会清除登录状态。

## QQ 音乐登录

1. 点击首页上方“QQ 音乐”账号按钮。
2. 默认打开“网页账号密码”：使用官方 QQ 页面输入自己的 QQ 号和密码；若显示二维码，选择页面中的“账号密码登录”。验证方式以官方页面实际提供为准。
3. 也可切换“手机 QQ 授权”，点击官方页面中的“一键登录”。本版补上了旧版拦截的官方 wtloginmqq 链接，并明确交给已安装的手机 QQ 处理。
4. 授权后返回合听，等待检测会话，或点“已完成登录，读取我的歌单”。打开 QQ 本身不代表已经登录音乐账号，必须完成官方授权与会话验证。
5. 已安装最新版 QQ 却提示安装，可能是网页唤起超时，并不证明 QQ 版本过旧。小米系统若限制应用间跳转，可检查相应权限；也可直接使用网页账号密码入口。

网易云仍使用原先的官方手机号验证码或账号密码页面。密码与验证码仅在官方网页中输入，合听不读取密码输入框。会话保存在 App 私有目录，不上传到下载网站或电脑同步服务。退出某个平台不退出另一个平台。

## 两个账号的具体歌单，在同一层选择

- 依次登录网易云和 QQ 音乐，两者可以同时保持登录。
- 默认的“全部歌单”页直接显示两个账号的具体歌单卡片。两家歌单交替排入同一个两列网格，每张标注来源，不再先展开平台目录。
- 同名或同 ID 的跨平台歌单分别保留，点击任一张即可查看其歌曲。
- 上方两个小账号按钮仅管理登录状态，不是歌单父目录。未登录的平台不会遮住已登录平台的歌单。
- “全部歌曲”继续支持两个平台的歌曲进入同一列表和播放队列；“本地歌单”保留原 MusicFree 功能。
- 下拉或点击“刷新”同步最新歌单。在线播放不依赖电脑服务，不需要手填地址或密钥。

## 已检查与待实测

本版增加了共享歌单网格、双账号同时显示、QQ 官方唤起协议、独立网页登录入口、并发登录回调等自动检查；APK 编译和签名也会在发布前检查。

用户已确认 0.7.0 在真实手机上可登录网易云。本次更新未使用用户的真实 QQ 账号，也没有小米 17 Ultra 真机，因此 QQ 客户端唤起、网页密码/验证码、平台风控、登录后的歌单读取及会员整首播放仍需在用户手机上实测。不能把自动检查视作全部歌曲已验证完整播放。

如遇问题，请提供平台、所选登录入口、手机系统版本及提示内容；不要发送密码、验证码、Cookie 或会话文件。
